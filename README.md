# Digital_High-Pass_Filters
Creation of Digital High-Pass Filters for Biomedical Imaging Using Mathematical Functions

1. EllipticalFilter2022.cpp calculates the Elliptical Filter;
2. Filter2D2017v3.cpp calculates the traditional HPF;
3. FourierConvolve2020.cpp calculates the Fourier Convolution Image (FCI);
4. IC.cpp calculates the First Order Derivative (FOD) and Intensity-Curvature Functional (ICF);
5. SRE2Dptf2022.cpp calculates the Pulse Transfer Function (PTF) of the ICF;
