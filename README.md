# Digital_High-Pass_Filters
Creation of Digital High-Pass Filters for Biomedical Imaging Using Mathematical Functions

EllipticalFilter2022.cpp calculates the Elliptical Filter
Filter2D2017v3.cpp calculates the traditional HPF
FourierConvolve2020.cpp calculates the Fourier Convolution Image (FCI)
IC.cpp calculates the First Order Derivative (FOD) and Intensity-Curvature Functional (ICF)
SRE2Dptf2022.cpp calculates the Pulse Transfer Function (PTF) of the ICF
